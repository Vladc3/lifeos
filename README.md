# Life OS

Local-first desktop app for habits and personal finance (Tauri 2 + React + SQLite). Built in public as a learning project.

Lokální desktop aplikace pro návyky a osobní finance. Jeden uživatel, offline, Windows + Linux. Žádný server, žádná telemetrie, data zůstávají na disku.

**Stav:** specifikace hotová, fáze 1 (kostra) se připravuje. Specifikace: [docs/PRD.md](docs/PRD.md), plán fází v kap. 10.
